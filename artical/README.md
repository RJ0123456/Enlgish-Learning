# Little Chapters

一个零依赖的英语短文学习网页。直接双击 `index.html` 即可打开。

## 已实现

- 120 篇短文（每篇约 300 词），覆盖科普、经济、环境、技术、人物传记、社会、职场 7 个主题
- 文章目录、搜索、7 个主题筛选和文章切换
- 每篇短文附带中文译文，默认隐藏，点击“译”按钮显示/隐藏
- 每篇短文预设 6-10 个重点单词及中文释义
- 单击文章中的任意单词，以气泡形式弹出发音按钮和词义；双击单词才会加入本篇生词表
- 英文朗读（播放 `audio/###.wav` 预置音频，播放按钮可在“播放文章”和“停止播放”之间切换）与单词发音
- 生词表中单击单词本身即可听发音，删除按钮已放大，方便点击
- 复制全文
- 使用浏览器 `MediaRecorder` 开始、结束、试听和删除临时录音，翻页或刷新后自动清除
- 字体大小缩放
- 响应式布局，柔和配色，无需登录

## 关于发音

文章朗读直接播放 `audio/001.wav` ~ `audio/120.wav` 中与章节 ID 对应的音频文件。单词发音仍使用浏览器内置的英文语音合成。

录音仅保存在当前页面内存中，刷新页面或切换文章后不会持久化。剪贴板、录音和音频加载等能力通常需要通过 `localhost` 或 HTTPS 访问；直接双击打开本地文件时，浏览器朗读和阅读功能依然可用。

## 部署

将整个文件夹上传到任意静态文件服务器（或使用如下命令本地预览）：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。
