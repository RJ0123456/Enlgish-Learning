# English Dialog

## 学习目标

通过情景对话学习英语

## 学习方式

阅读和背诵短文. 学习单词、短语和对话

## 内容和使用方式

1. 阅读"英文情景对话分类大全_完整对话版.csv"
    - 里面有各种类别的情景对话
    - 对话中包含英文和译文
    - 每个对话有音频文件，音频文件在audio目录下面
2. 使用方式为网页，简单部署后在各个终端可以打开使用
3. 每个情景是一篇，每篇一个页面
4. 有生词表
    - 每篇2到3个预设的生词
    - 双击可以添加单词为生词
    - 每个生词可以删除
    - 单击每个生词可以读音
5. 单击对话的内容的中的单词，然后以气泡的方式展示单词的意思并可以播放发音
6. 译文默认是隐藏的，但可以点击显示
7. 有播放按钮. 当点击播放按钮就开始播放audio目录下面对应的音频文件
8. 生词以高亮的形式显示
9. 有一个复制按钮，点击可以复制对应篇目的对话文字内容
10. 可以点击开始和结束录音.这样在学习中可以随时录制自己的阅读或背诵的声音，然后自己听效果.录制的声音可以随时手动删除，刷新页面或翻页后自动删除不做保存

## 设计

1. 界面设计颜色柔和，适合人长时间盯着看
2. 页面有字体大小缩放按钮
3. 页面简洁干净
4. 页面无需登录等形式，打开链接直接可以使用
5. 播放按钮的icon修改：使用音乐播放的icon，有开始有停止的切换显示
